# Student Record Management System

A beginner-friendly Python project for managing student records using JSON file storage.

## Features

* Add Student
* View Students
* Search Student
* Update Student
* Delete Student
* Find Top Student
* Calculate Average Marks
* Store student data in JSON file

## Technologies Used

* Python
* JSON
* File Handling

## Concepts Practiced

* Variables
* Lists
* Dictionaries
* Conditions
* Loops
* Functions
* File Handling
* Exception Handling
* JSON

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

5. Select an option from the menu.
